# UI-00：前端仓库审计（对照《科幻操作面板 UI 规范 V1.0》）

日期 2026-11-05。只审计、不改代码（规范第 13 节第一步）。范围：`web/`（React 客户端）与 apid 已有接口（`docs/api/ROUTES.md`）。

## 1. 现状

| 项 | 现状 |
|---|---|
| 框架 | React 19 + TypeScript 5.8 + Vite 6。没有 UI 组件库，也没有 CSS 框架 |
| 规模 | `web/src` 约 2400 行，共 15 个文件 |
| 路由 | 不用路由库。`App.tsx` 用 state 切换 7 个页面：总览、订单、持仓、风险、告警、审计、急停；`#showroom` 打开组件陈列室 |
| 状态管理 | 只用 React hooks，没有全局状态库。登录状态和偏好存在 `prefs.ts`，令牌在 sessionStorage，偏好在 localStorage |
| 实时通信 | `status.ts` 每 3 秒串行轮询 `/v1/status`，有一个看门狗：10 秒没有成功就判为“过期”。apid 有 `WS /v1/stream`，但网页还没用 |
| 数据接口 | 网页只用到 `/v1/whoami`、`/v1/status`、`/v1/orders`、`/v1/commands`（含二次确认）、`/v1/alerts`、`/v1/audit` |
| 图表 | `ui.tsx` 里自写了一个 SVG `Sparkline`。没有图表库 |
| 地图 | 没有 |
| 组件 | `ui.tsx`：Icon、ModeBadge、Tag、Button、StatCard、PnL、Notice、Empty、ThemeToggle、LangToggle、Sparkline |
| 设计令牌 | `styles.css`：深色、浅色两套颜色令牌；盈利用蓝、亏损用橙（对色弱友好）；有专门的模式徽章颜色；尊重 `prefers-reduced-motion` |
| 多语言 | `i18n.tsx`：中文、英文 |
| 测试 | Playwright：`design.spec.ts`（含视觉快照）、`alerts.spec.ts`、`client.spec.ts`、`i18n.spec.ts`；有 axe 无障碍检查；用 knip 做无效代码检查 |
| 字体与资源 | 用系统字体栈，不加载网络字体；`web/public` 为空 |

### 已经做对、要保留的

- **失败即关闭的显示**：数据不新鲜就显示“未知”，不拿旧值冒充当前值（`status.ts`、`Views.tsx`）。这正是规范 AC-05、AC-06 的要求。
- **模式徽章只有三种**：PAPER、HALT、未知。
- **高危命令走后端二次确认**：界面上没有直接下单的入口。
- **颜色不是唯一信号**：涨跌另带 ▲▼ 和正负号。

## 3. 技术选型建议（不引入大型依赖）

| 用途 | 建议 | 理由 |
|---|---|---|
| 行情图 | **继续用自写的 SVG 或 Canvas**；需要十字线、缩放时再评估轻量库（例如 lightweight-charts，Apache-2.0，约 45 KB） | 首期是日线，数据量小，自写就够用；引入任何库都要过许可证检查 |
| 地图 | 用 **d3-geo**（ISC）投影，加上**本地打包的 Natural Earth 低精度世界轮廓**（公共领域，转成 TopoJSON 后约 100 KB） | 不联网、许可证干净、体积小；不用 Mapbox 这类需要联网或令牌的服务 |
| 动效 | 只用 CSS 动画和过渡，不引入动画库 | 能跟随 `prefers-reduced-motion` 和应用内开关一键关闭 |
| 状态 | 继续用 hooks，加一个小型的“快照存储”（Context 加 reducer），供实时通道写入、各面板读取 | 规模不大，不需要 Redux 这类库 |
| 路由 | 暂不引入路由库：外壳切“指挥中枢”和“详情页”两层就够 | 以后页面变多再评估 |

所有新依赖都要过 H-01 的许可证检查、漏洞扫描和 knip；字体照样只能用系统字体，或者 OFL 许可的本地字体。

## 4. 演示模式布局原型（UI-02）的做法

1. **新建外壳**：`web/src/console/`，按规范第 3 节分区。现有的 7 个页面挂在“详情”导航下，不删除。
2. **DEMO 数据**：放在 `web/src/demo/`，只在 `vite --mode demo` 下打包。
   - 生产构建加一项测试：确认产物里不含 demo 模块，也不含随机数生成。
   - 在 DEMO 模式下：顶栏常驻醒目的 DEMO / SIMULATED 标记；不请求任何交易接口；不能触发命令。
3. **模块状态**：没有后端接口的模块，在真实模式下显示“未接入”或“未启用”，不显示样例数据。
4. **验收**：
   - 截图：1920×1080、2560×1440 两种尺寸；
   - 可访问性：axe 检查、键盘切换双视图、减少动效模式；
   - 视觉快照纳入 `design.spec.ts`。
5. **范围**：原型阶段不新增 apid 接口。接口逐个随对应任务（B-03b、B-04、R-08 等）接入。

## 5. 风险

- **效果图用的是虚构数据**：原型的样例必须放在 DEMO 模块里，真实模式下绝不出现。
- **动效与安全信息的冲突**：HALT、UNKNOWN、数据过期的提示优先级最高，不加动效（S-16 原则 2）。
- **地图事件的定位**：情报模块出来之前，地图上只显示 DEMO 热点或“情报未接入”，不放真实坐标。
