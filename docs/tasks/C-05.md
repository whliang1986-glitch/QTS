## 目标

配置以 TOML 加载、按内容哈希定版本，每次变更在账本留下只追加的审计轨迹；密钥只从系统凭据存储读取，
任何文本化都不会泄露；ModeConfig（C-04）与交易日历临时覆盖（D-03）从配置加载。

## 非目标

- 不创建、不修改任何受保护配置（`config/risk`、`config/live`）与凭据；那是 Dylan 的操作。
- 不做日志脱敏框架（C-06）；不做配置热加载。

## 允许修改范围

- 可以改：`server/storage/config.py`、`server/storage/credentials.py`、`server/risk/config.py`、
  `server/data/calendar_config.py`（均新建）、`pyproject.toml` / `uv.lock`（keyring 依赖）、相应测试、本任务单。
- 不得改：`config/risk`、`config/live`、凭据目录、其他任务的公共接口。

## 涉及的受保护路径

无（只提供加载代码；受保护配置文件的路径由调用方给出，由 Dylan 维护）。

## 接口与不变量

- `load_toml(path, name) -> LoadedConfig`：失败即关闭（缺失、BOM、编码、语法错误抛 `ConfigError`）；浮点按 Decimal 解析，
  nan / inf 拒绝；键名只能 ASCII；内容深度冻结；
  版本 `name@sha256[:12]`；字段名像密钥（password、token、api_key、private_key、credential 等）一律拒绝，错误信息不回显取值。
- `ConfigHistory.record(...)`：与上次记录的版本不同则追加审计事件 `config_version`（含 name、sha256、previous、path），
  重复加载不写，回滚也留痕；`versions(name)` 返回轨迹。复用账本审计表，无迁移。
- `parse_mode_config(loaded)`：读 `[mode]`，`config_version` 由加载器生成、文件里出现即拒绝；校验错误只报字段名。
- `parse_calendar_overrides(loaded)` / `nyse_from_config(...)`：`[calendar]` 的 `adhoc_closures`（本地日期数组）与
  `[[calendar.adhoc_early_closes]]`（`date` 本地日期 + `close` 本地时间，按美东解释并转 UTC）；类型严格、未知字段与重复日期拒绝。
- `SensitiveValue`：str / repr / format 一律 `***`，不可序列化、不可哈希，`reveal()` 才取明文；
  `KeyringCredentialStore` 不可用或缺少凭据抛 `CredentialUnavailableError`；没有写入接口。
