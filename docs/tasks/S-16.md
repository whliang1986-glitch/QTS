## 目标

在 S-13 的设计令牌之上加一层“动效层”，让界面更有科技感，但不影响信息的准确和安全操作。

## 风格方向

- 深色底，霓虹青蓝的点缀色；数据卡片用半透明玻璃质感，带细微光晕；背景是缓慢流动的网格或粒子（可以关掉）。
- 有意义的动效：
  - 数字变化时滚动过渡，涨跌时轻微闪一下颜色；
  - 净值曲线绘制时有扫描线效果；
  - 连接状态用呼吸灯；告警到来时边框有脉冲；
  - 产业链星图：情报出现时，影响从源头沿着连线“点亮”到下游的公司。
- “指挥中心”大屏视图：适合挂在第二块屏幕上，集中显示净值、持仓、情报流和风控状态。

## 原则（必须遵守）

1. **动效只做表现**，不得遮挡或延迟安全信息。
2. **关键信息保持静态、清晰**：
   - 模式徽章（PAPER / HALT / UNKNOWN）、急停按钮、风控状态、“结果未知”的提示，都不加花哨动效；
   - 大屏视图里，HALT 与“数据过期 / 断连”的提示优先级最高，不被其他动效盖住。
3. **不靠动画误导数据**：过渡动画里不显示没有确认的中间值；数字滚动只在新值已经确认之后发生。
4. **动效必须和数据一一对应**：产业链“点亮”的路径必须与 S-15 的传导数据完全一致，不做纯装饰的假路径。
5. **减少动效**：遵守系统的“减少动态效果”设置，并提供应用内开关；关掉以后所有信息仍然完整可用。
6. **性能预算**：有帧率与 CPU 预算；低配机器自动降级（关掉背景粒子和光晕）。
7. **字体**：仍须通过 H-01 的字体许可检查（只允许 OFL、Apache、MIT，必须登记）。
8. **不联网**：不引入需要联网加载的字体、图片、脚本等资源。

## 回滚

动效层是独立的样式与组件开关，关闭或回退即可，界面回到 S-13 的静态版本。
