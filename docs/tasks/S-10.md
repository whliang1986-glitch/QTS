|---|---|
| 任务 ID | S-10 |
| 优先级 | P1 |
| 里程碑 / 门禁 | M2 / G7 |

| 估算工日 | 1 |
| 状态 | ACCEPTED |

## 目标

- 在 `server/storage/approval_queue.py` 实现只追加的 `ApprovalQueue`：
  - 统一托管 `ORDER_INTENT`（辅助实盘/事件驱动）、`STRATEGY_PROMOTE`、`FACTOR_PROMOTE`、`TRADING_LIST_ADD`、`RISK_LOOSEN`；
  - 仅 `owner` 可通过 `/v1/approvals/{approval_id}/decide` 批准或拒绝（拒绝必填原因），AI 与 `viewer` 无审批入口；
  - 超时未批自动过期失效（`expire_stale`），过期后不可批准（失败即关闭）。

## 验收标准

- [x] 只追加 SQLite 触发器阻止 `UPDATE` / `DELETE`
- [x] 仅 `owner` 可审批，写审计；`viewer` 被 403 拒绝
- [x] 过期审批单无法批准
- [x] 集成测试与路由清单校验通过（`tests/integration/risk/test_watchlist_and_approvals.py`）
