# B-05y：交易核心真实数据源装配与连接加固

| 字段 | 内容 |
|---|---|
| 任务 ID | B-05y |
| 优先级 | P0 |
| 里程碑 / 门禁 | G4 前置 |
| 前置任务 | B-05w、B-05x、D-04、R-02b |
| 状态 | ACCEPTED |

## 目标

补齐 `B-05w` 残留风险表中缺失的六个真实数据源实现（公司行动、止损冷却期、当日开盘净值、策略回撤、账户同步监控、时钟偏差探针），并修复 `ConnectionSupervisor` 只读参数透传与 `IbkrReadOnlyAdapter` 收到 `1100`（TWS 与 IB 服务器断开）时的连接状态与事件同步。

## 改动

- `server/app/wiring.py`：
  - `LakeCorporateActionSource`：从数据湖 `normalized/corp_actions` 读取拆股/合股记录并按交易日历开盘时刻构造 `CorporateAction`，供对账（R-07）自动识别拆股持仓变动；
  - `LedgerStopCooldownSource`：从账本读取保护性止损成交并按交易日历计算 `StopCooldown`（已过交易日数与是否跨过再平衡日）；
  - `DailyNavBook`：按 `(account_id, session_day)` 登记并读取当日开盘净值，拒绝跨值覆盖，未登记返回 `None`；
  - `StrategyDrawdownBook`：追踪各策略峰值与当前净值并计算 `[0, 1]` 回撤比例，过期或回拨的策略自动剔除以触发 fail-closed；
  - `AccountSyncMonitor`：作为 `Feeds.account_synced` 与 `health_reporter` 中 `"account_sync"` 检查的单一事实来源，要求券商已连接、对账通过且同步未过期；
  - `clock_skew_probe`：测量参考时钟往返耗时并计算中点时钟偏差（毫秒），超时、回拨或无时区返回 `None`。
- `server/broker/ibkr/connection.py`：
  - `ConnectionSupervisor._try_connect` 按 `policy.readonly` 连接，不再写死 `readonly=True`。
- `server/broker/ibkr/adapter.py`：
  - 跟踪 `_broker_lost`（收到 `1100` 置 `True` 并推 `ConnectionEvent(DISCONNECTED)`，收到 `1101/1102` 清除并推 `ConnectionEvent(CONNECTED)`）；`connected` 属性在 `_broker_lost` 期间返回 `False`，使健康检查与心跳同步感知 `1100` 断连。

## 验收标准

- [x] 六个真实数据源均具备正常路径与 fail-closed 失败路径测试
- [x] `AccountSyncMonitor` 同时提供 `is_synced` 与 `check`，消除双来源不一致
- [x] `IbkrReadOnlyAdapter` 收到 `1100` 时 `connected` 变为 `False` 并发出 `DISCONNECTED`，收到 `1102` 恢复为 `True` 并发出 `CONNECTED`
- [x] `ConnectionSupervisor` 按 `policy.readonly` 传递只读参数
