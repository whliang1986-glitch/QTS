## 目标（V4.1 8.3 & economic-gate.md 第 0–1 节）

- 在 `server/storage/experiments.py`（并由 `server/backtest/experiments.py` 导出）实现 `ExperimentRegistry`：
  - 每次回测实验落入 `meta.db` 的 `experiments` 表，通过 SQLite 触发器禁止 `UPDATE` / `DELETE` / `REPLACE`；
  - `trial_count(strategy_id)` 统计该策略所有版本的累计试验次数，防止删除失败实验刷高 Deflated Sharpe；
  - 封存样本外单次使用锁：同一 `(strategy_id, strategy_version)` 的 `is_out_of_sample=True` 评估只允许登记一次，二次窥探抛 `ConflictError`。

## 验收标准

- [x] SQLite 只追加触发器阻止 `UPDATE` / `DELETE` / `REPLACE`
- [x] 幂等重放返回 `False`，同 ID 不同内容或二次窥探样本外抛 `ConflictError`
- [x] `trial_count(strategy_id)` 准确统计累计试验次数
