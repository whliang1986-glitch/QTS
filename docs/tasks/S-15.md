## 目标

在自选列表里点一只标的，就能看到和它相关的情报；点开一条情报，能看到它影响的行业、具体股票，以及传导路径。

## 设计要点

1. **标的的情报流**：按时间倒序列出和这只标的相关的情报，每条显示：
   - 来源（A-15 的显示名称）、发布时间与系统收到时间；
   - 可信度标签：官方 / 媒体 / 社交；
   - 状态标识：已核实 / 未核实 / 有争议；
   - 原文链接。
2. **情报详情**：
   - 事件摘要（AI 生成的标“AI 生成”，并附原文摘录）；
   - **影响的行业与具体股票**：来自 A-14 的排名，正面、负面分开列出，显示影响分；
   - **传导路径**：来自 A-13、A-14，例如“事件 → 公司 A → 供应商 B（收入占比 35%）”，每一段都能点开看数据出处；
   - 涉及的标的是否在自选、是否在交易名单。
3. **页面明确标注“仅供研究，不触发下单”**。这里没有任何下单入口；看到的建议要交易，只能走策略与风控（S-14 第一节的三层定义）。
4. **未核实、有争议的情报**显示醒目标识，不进入影响排名（与 A-12、A-14 一致）。
5. **数据不可用时如实显示**：情报库或排名读不到，显示“无法获取”，不显示“没有情报”。

## 验收标准

- [ ] 从自选列表进入标的情报流；情报按时间倒序，带来源、时间、可信度与核实状态
- [ ] 情报详情显示影响的行业、股票与传导路径，每一段都能追溯到出处
- [ ] 页面没有任何下单入口，并标注“仅供研究，不触发下单”
- [ ] 未核实、有争议的情报有标识，不出现在影响排名里
- [ ] 读不到数据时显示“无法获取”
- [ ] 中英文、深浅主题、手机布局；axe 无障碍检查覆盖
