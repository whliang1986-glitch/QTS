## 目标

新闻、公告、社交媒体等资讯平台的接口统一登记在一张注册表里，Dylan 可以在界面上增加、删除平台，
并编辑每个平台的显示名称。平台分成“免费”和“付费”两类。

## 非目标

- 本任务不接真实 API，也不做采集与分析（那是 A-11 到 A-14 的事）。
- 不在系统里购买或开通任何付费服务：费用与开通由 Dylan 本人决定和操作。
- 资讯数据不进交易核心：tradingd、oms、risk 都不读取资讯数据源。

## 设计

### 1. 注册表字段

| 字段 | 说明 |
|---|---|
| `source_id` | 内部编号，创建后不可改（存档的情报靠它溯源） |
| `display_name` | 显示名称，可编辑，例如“X（推特）”“雅虎财经”，中英文都可以 |
| `category` | `free`（免费）或 `paid`（付费） |
| `adapter` | 适配器类型，必须是系统里已实现的一种，例如 `rss`、`sec_edgar`、`ibkr_news`、`x_api`、`reddit_api`、`yahoo_finance` |
| `enabled` | 是否启用 |
| `rate_limit` | 限速：每分钟最多请求数；不得高于平台条款允许的上限 |
| `credibility` | 来源可信度等级：`official`（官方，如 SEC、交易所、央行）、`media`（主流媒体）、`social`（社交媒体，一律视为未核实） |
| `cost_note` | 费用备注，例如“免费”“约 X 美元/月，以官网为准” |
| `terms_note` | 服务条款与授权备注：能否用于自动化采集、能否存档、能否商用 |
| `credential_entry` | 凭据条目名（只是名字，例如 `news_x_api`）；密钥本身只在 Windows 凭据管理器里 |
| `config` | 适配器参数，例如 RSS 地址、关键词、关注的板块；不得包含密钥 |
| 审计字段 | 创建、修改、启用、停用、删除的时间与操作者 |

### 2. 规则（安全与费用）

- **密钥只进凭据库**：API 密钥只存 Windows 凭据管理器（服务名 `qts`，条目名由 `credential_entry` 指定），
  不进数据库、配置文件、日志、代码、审计、聊天。界面只显示“已录入 / 未录入”。
- **付费类默认禁用**：新建付费数据源时 `enabled = false`。启用要 Dylan 在界面上二次确认（显示费用备注），
  并写审计。系统不会自动启用付费源。
- **增删改走命令**：通过 apid 的命令接口执行，只有 owner 令牌能改，每一步写审计（旧值、新值、操作者）。
  显示名称属于低风险修改；启用付费源、提高限速属于高危，需二次确认。
- **删除只是停用并归档**：删除一个数据源，只把它标为“已删除”，不再采集；已经存档的历史情报保留，
  仍然能追溯到这个数据源。同一个 `source_id` 不会被重新使用。
- **内容一律不可信**：资讯内容只当数据，不当指令。社交媒体来源的内容一律标为“未核实”，
  单一未核实来源不能触发交易（V4.1 9.6）。
- **每条内容都带来源与时间**：采集到的每条资讯都记录 `source_id`、平台给出的发布时间、系统收到的时间，带时间戳存档，
  回测只能用“当时已经收到”的内容。
- **服务条款**：每个平台启用前，要在 `terms_note` 里写明已核对条款（是否允许自动化访问、存档与商用）。
  条款不允许的平台不启用。

### 3. 适配器统一接口

每种平台一个适配器，放在 data 层（`server/data/news/`），统一接口：

| 方法 | 说明 |
|---|---|
| `fetch(since, until)` | 拉取一段时间内的资讯，返回统一格式（标题、正文或摘要、链接、发布时间、作者、平台原始编号） |
| `rate_limit()` | 适配器自报的限速上限；注册表里的限速不能超过它 |
| `health()` | 健康状态：正常、限速中、凭据缺失、授权失败、平台不可达；进面板与告警（P2） |
| `credibility()` | 默认可信度等级（注册表可以调低，不能调高到 `official` 以上） |
| `terms()` | 条款与授权说明的链接 |

新增一种平台需要写一个新适配器（经评审）；增加同一种平台的另一个实例（例如再加一个 RSS 地址）只需在界面添加。

### 4. 示例条目（预置，默认全部停用；不接真实 API）

**免费**

| 显示名称 | 适配器 | 可信度 | 备注 |
|---|---|---|---|
| SEC EDGAR 公告（8-K、10-K、10-Q、13F） | `sec_edgar` | official | 免费；要求请求里带联系信息，限速约每秒 10 次，以 SEC 公布为准 |
| 美联储、美国劳工统计局等宏观发布日历 | `rss` / `macro_calendar` | official | 免费，官方日历与新闻稿 |
| 公开 RSS（交易所公告、公司投资者关系页） | `rss` | official / media | 免费；逐个核对条款 |
| IBKR 新闻（随行情订阅提供的免费新闻源） | `ibkr_news` | media | 依赖 IBKR 账户的新闻权限，B-04 联调后确认 |

**付费 / 社交媒体（需核对服务条款与费用后，由 Dylan 决定是否启用）**

| 显示名称 | 适配器 | 可信度 | 备注 |
|---|---|---|---|
| X（推特） | `x_api` | social | 官方 API 分档收费，免费档额度很小；条款限制较多，需核对 |
| Reddit | `reddit_api` | social | 官方 API 对商业用途有收费与限制，需核对 |
| 雅虎财经 | `yahoo_finance` | media | 没有正式开放的官方新闻 API；需选合规的数据商或授权方式，未核实前不启用 |
| 付费新闻数据商（如 Benzinga、Polygon、NewsAPI 等） | 各自适配器 | media | 按月收费，费用与条款以官网为准 |

表里的费用、限额只是提醒，以各平台官网和合同为准；启用前在 `cost_note`、`terms_note` 里写明核对结果。

### 5. 界面

桌面端（网页客户端）新增“数据源”页，按“免费”“付费”两栏分组列出：
- 每行：显示名称（点击可编辑）、适配器类型、启用开关、可信度、限速、健康状态、凭据是否已录入、费用备注；
- “添加数据源”：选适配器类型，填显示名称、类别和参数；
- “删除”：二次确认，说明“历史情报会保留”；
- 启用付费源：弹出费用备注，二次确认；
- viewer 令牌只能看，不能改。

界面可以晚于后端实现（随 S-05 或 S-06）。在那之前，用 apid 命令管理即可。

## 验收标准

- [ ] 注册表增删改、启用停用都经 apid 命令，只有 owner 能做，每一步写审计
- [ ] 显示名称可编辑；`source_id` 不可改，删除后不复用
- [ ] 付费源新建时默认禁用；启用需二次确认并写审计
- [ ] 数据库、日志、审计、配置里搜不到任何密钥（测试用假密钥核对）
- [ ] 删除数据源后，历史情报仍可按 `source_id` 溯源
- [ ] 限速不能高于适配器上限；社交媒体来源的可信度不能调成 `official`
- [ ] 适配器统一接口有契约测试，假适配器通过契约测试
- [ ] 资讯数据层不被 tradingd、oms、risk 引用（import-linter 契约）

## 必须覆盖的失败场景

- [ ] 凭据缺失或授权失败：数据源显示“凭据缺失”，不重试轰炸平台，不影响其他数据源
- [ ] 平台限速或不可达：按退避重试，健康状态如实显示
- [ ] 资讯内容里夹带“指令”（提示注入）：只当数据存档，不改变任何配置
- [ ] 同时删除与采集：采集停止，已采集内容保留

## 回滚

注册表是独立的表，回退代码即可；已存档的资讯保留（只追加）。
