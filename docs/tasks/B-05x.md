# B-05x：关键组件校验下沉到风控层

| 字段 | 内容 |
|---|---|
| 任务 ID | B-05x |
| 优先级 | P0 |
| 里程碑 / 门禁 | G4 前置 |
| 前置任务 | B-05w、R-08 |
| 状态 | ACCEPTED |

## 目标

把关键组件（`broker`、`account_sync`、`quotes`）的完整性校验从装配层 `server/app/wiring.py` 下沉到风控层（`server/risk/config.py`、`CoreInputs` 与 `build_trading_core`），并在 `RunStateMachine` 拒绝空组件清单或非正时效，堵住直接构造 `CoreInputs` 或调用 `build_trading_core` 绕过关键组件门禁的路径。

## 改动

- `server/risk/config.py`：
  - 新增 `REQUIRED_CRITICAL_KINDS`（锁定 `broker: ACCOUNT`、`account_sync: ACCOUNT`、`quotes: DATA`）与 `require_critical_components`；
  - 校验组件无重名、类别与布尔标记合法、`stale_after > 0`、三个关键组件均登记且 `critical=True`、且类别未被篡改（防止把 `broker` 或 `quotes` 改成 `OTHER` 绕过恢复检查 `account_ok` / `data_ok`）；
  - `parse_health_config` 复用同一校验函数。
- `server/risk/assembly.py`：
  - `CoreInputs.__post_init__` 与 `build_trading_core` 均调用 `require_critical_components`。
- `server/risk/run_state.py`：
  - `RunStateMachine.__init__` 拒绝空组件清单与 `stale_after <= 0`。
- `server/app/wiring.py`：
  - `core_inputs` 复用 `require_critical_components`。

## 验收标准

- [x] 直接构造 `CoreInputs` 或调用 `build_trading_core` 时，缺关键组件、关键组件被降为非关键、关键组件类别被篡改或 `stale_after <= 0` 一律抛 `ValueError`
- [x] `RunStateMachine` 拒绝空组件清单与非正 `stale_after`
- [x] `parse_health_config` 与 `core_inputs` 共用同一份关键组件规则
