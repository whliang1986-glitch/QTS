## 范围

- 只做 DEMO 静态原型：独立入口 `web/demo.html`，演示数据在 `web/src/demo/`，**不进生产构建**。
- 指挥中枢的面板在 `web/src/console/`，用数据契约 `types.ts` 驱动：
  - 每个区块要么有数据，并附数据时间与来源；
  - 要么显示“未接入”。
  - 以后接真实接口时直接复用这些面板。
- 不新增 apid 接口，不改现有页面，也没有任何下单、改仓、改风控的控件。

## 做了什么

- **布局**（规范第 3 节）：顶栏、主导航，左边市场，中间指挥中枢，右边账户和持仓分布，底部依次是交易动态、策略表现、风控、系统状态。
  - 导航里除“AI 指挥中枢”外都是禁用状态，鼠标悬停显示“规划中”。
- **双视图**（规范第 4 节）：
  - 决策分析和全球情报一键切换：只换中间区域，外围面板不变，键盘可以操作。
  - 决策分析视图里，AI 卡片显示“未启用”，模式卡片只读。
- **全球情报**：
  - 底图用本地打包的 Natural Earth 1:110m 轮廓，由 d3-geo 投影；热点有脉冲动效。
  - 点热点打开事件详情：来源、类别、关联资产、定位依据与置信度；模型观点标明“非事实，未经证实”。
  - 没有定位的事件不上地图，单独计数。
  - 图例按严重度分级。
- **安全显示**：
  - 顶部常驻 DEMO / SIMULATED 横幅；模式徽章显示“DEMO · PAPER”，并用 DEMO 的配色。
  - 顶部徽章以最严重的状态为准：HALT 优先，其次是“未知”；风控快照不可用也算“未知”。
  - 横幅、徽章、HALT 都不加动效。
  - 动态流里的标签写“策略建议”，不写“AI 建议”（首期没有 AI）。
- **动效**：
  - 有“减少动效”开关，也跟随系统的 `prefers-reduced-motion`；
  - 只用 CSS 动画，不引入动画库。
- **依赖**：d3-geo、topojson-client、world-atlas，以及它们的类型包，全部是 ISC 或 MIT 许可。已登记在 `docs/licenses/THIRD_PARTY.md` 和 `MAP_DATA.md`。

## 测试（实际运行）

- `npx playwright test`：默认 86 条全部通过；`SHOTS=1` 生成截图时为 152 条，也全部通过。其中 `tests/demo.spec.ts` 覆盖：
  - DEMO 标记、账户号脱敏；
  - 记录全部请求，没有 /v1 请求，也没有外部地址；
  - 双视图切换与键盘操作；
  - 热点详情；
  - 减少动效；
  - axe 无障碍检查；
  - 1920×1080 和 2560×1440 两种分辨率下没有横向溢出。
- `uv run pytest tests/arch/test_web_demo_isolation.py`：
  - 生产入口不引用 demo；
  - 不把 demo 加进构建入口；
  - demo 不用随机数；
  - demo 页的 CSP 禁止网络连接；
  - 面板不自己生成数据。
- `npm run typecheck`、`npm run build`：生产产物里只有 index 页面，没有 d3 和 demo 的代码。
- `npx knip`：通过。`check_licenses.py`：281 个依赖，0 禁止、0 需确认。
- 截图：`docs/design/screenshots/console-demo-*.png`。2560×1440 的情报视图那张大于 500 KB，没有提交。

## 没有做（NOT RUN）

- 录屏（规范第 12 节）。
- 异常降级场景（HALT、UNKNOWN、未接入）的截图与测试。降级逻辑已经写好，演示数据里只有正常场景。
- 真实数据模式的截图（还没有接口）。
- 1920×1080 下首屏没有完全容纳系统状态面板，要向下滚动。规范 AC-01 要求不裁切，下一轮再压缩布局。
- 面板里有几处写死的文案（“已扣成本”“美东”“IBKR 模拟账户”），接真实数据时要改成由数据驱动。
- 多语言：原型只有中文，接入正式外壳时走 `i18n.tsx`。
