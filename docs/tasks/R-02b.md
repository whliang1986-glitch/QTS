## 目标

V4.1 R-02：超限全部拒绝（能缩量的缩量）；规则命中可解释。阈值全部来自 R-02a 的当前生效参数（Dylan 批准，面板调严立即生效）。

## 设计

`server/risk/limits.py`，每条规则带 rule_id 与版本，所需上下文缺失一律拒绝；`build_rule_set` 在 DefaultDenyRule 之后加入全部阈值规则。

| 规则 | 适用 | 结论 |
|---|---|---|
| 单笔名义金额 ≤ max_order_notional_nav × NAV | 开仓 | 缩量 / 拒绝 |
| 单标的市值（持仓 + 其他未结束买单 + 本单）≤ ETF / 个股上限 × NAV | 开仓 | 缩量 / 拒绝 |
| 总敞口 ≤ max_total_exposure_nav × NAV；买入后可用现金 ≥ min_cash_buffer_nav × NAV（可用 = 已结算 + min(未结算, 0) − 其他买单），取更严 | 开仓 | 缩量 / 拒绝 |
| 日内亏损（相对开盘净值）≥ max_daily_loss_nav | 开仓 | HALT（经 ModeManager 持久化） |
| 策略回撤 ≥ max_strategy_drawdown（回撤须为 [0, 1] 的比例，否则拒绝） | 开仓 | 拒绝（暂停该策略开仓） |
| 未成交订单数（不含保护性止损、不含自身）≥ max_open_orders | 开仓、减仓 | 拒绝 |
| 一分钟内签发笔数 ≥ max_orders_per_minute（改单不计） | 开仓、减仓 | 拒绝 |
| 限价相对最新价偏离 > max_limit_deviation（含改单，按新价） | 开仓、减仓的限价单 | 拒绝 |
| 止损后冷却期：不少于 stop_cooldown_trading_days 个交易日，且须已过一个再平衡日 | 开仓 | 拒绝 |

- **保护性止损豁免全部阈值规则**（R-04 移交：否则缩量被改判拒绝、持仓失去保护）；减仓只受订单数、频率、限价偏离约束。
- 单标的与总敞口规则自身拒绝负持仓（不依赖 DefaultDeny 的顺序）；资产类别显式对应上限，无对应即拒绝。
- 命中说明带上限与余量数值。
- `RiskContext` 扩展：nav、start_of_day_nav、strategy_drawdown、recent_submissions、stop_cooldown（`StopCooldown`：止损后交易日数、
  是否已过再平衡日，由上下文提供者按交易日历计算）。
- 不在本任务：报价陈旧、价差、时钟偏差（R-03 数据门禁）；冒烟策略单笔上限（T-02 定策略登记后接入）。
- “笔/分钟”的计数窗口 1 分钟是单位定义，不是可调阈值。

## 移交

- **R-05 / S-01（G3 前置）**：日内亏损 HALT 现在会由规则自动触发；HALT 下模式门禁拒绝一切订单，包括保护性止损。
  HALT 后才成交的开仓单需要新建保护性止损，会被拒绝，新持仓无保护。须二选一：HALT 下为 PROTECTIVE_STOP_SOURCE 的保护性止损开
  专项通道（只放行止损，规则照查），或 HALT 同时逐单撤销未成交开仓单。日内亏损还要由账户监控独立触发 HALT（不只靠下单前检查）。
- **R-03 / S-01（G3 前置）**：上下文提供者计算 nav（折算美元）、开盘净值（剔除当日出入金）、策略回撤（[0, 1] 的正比例）、
  近期签发时间、止损冷却（交易日历；“查不清”必须给 None，不能给空映射）；数据新鲜度门禁（报价陈旧、价差、时钟偏差）。
- **说明**：可用现金不足时 DefaultDeny 的不加杠杆检查直接拒绝，缩量只发生在“现金够、但扣掉缓冲不够”的区间（偏严）；
  部分成交后改单，改单数量为意图总量，已成交部分已在持仓中，会被计两次（偏严，可能误拒）。
- **后续**：改单不计入下单频率；改单风暴可能撞上券商消息限速，是否加改单频率上限（新参数）由 Dylan 定。
  命中说明的金额格式在面板阶段统一（与参数模块的 `_text` 一致）。
- **T-02**：冒烟策略登记后接入 smoke_order_nav（仅模拟盘），实盘模式下该策略不可启用。
- **风控面板任务**：ADR-16 补充的每月定期复核（模拟盘阶段逾期只提醒）。
