## 目标

apid 可以安全地上线：
- 只认可吊销的长随机令牌；
- 高危命令须二次确认令牌；
- 离开本机回环地址必须使用 TLS；
- 会话与操作写入 api.db 审计。

完成后，生产 apid 入口可以启动。

## 非目标

- 不做客户端证书（mTLS）和账户体系，角色只有 owner 与 viewer（V4.1 10.2）。
- 不做 VPN 配置（运维事项，见运行手册）。
- 不生成证书：证书由运维用 openssl 生成（见运行手册），私钥放 `secrets/`，由 apid 进程读取，开发过程不读不写。

## 接口与不变量

- **令牌**：
  - 格式 `qts_<token_id>_<secret>`，secret 为 32 字节随机数（`secrets.token_urlsafe`）；
  - api.db 只存 secret 的 SHA-256，比对用 `hmac.compare_digest`；
  - 明文只在签发时输出一次，不进日志、审计、URL。
- **api.db**：
  - 只有 apid 写（单写者）；
  - 令牌事件（签发、吊销）与审计都只追加，触发器拒绝 UPDATE 和 DELETE；
  - 当前状态由事件推出；
  - 结构版本不对，拒绝打开。
- **令牌管理**：`python -m server.app token issue|revoke|list`。
  - 必须拿到 apid 的单写者锁；apid 在运行时拒绝执行，提示先停止 apid；
  - 停 apid 不影响交易，tradingd 照常运行；
  - 签发必须给有效期，上限 365 天。
- **在线吊销**：`POST /v1/tokens/{token_id}/revoke {reason}`。
  - 只有 owner 能调用，立即生效，也能吊销自己的令牌，写审计；
  - 返回码：已吊销仍返回 200（幂等）；不存在返回 404；reason 为空返回 422；api.db 写入失败返回 503；
  - 只能吊销，不能签发或延长有效期。
- **认证失败限流**：同一来源 60 秒内失败 20 次，之后 60 秒内一律返回 429，并写审计。
- **二次确认（高危命令）**：
  - 先 `POST /v1/commands/confirmations {name, params}`，得到 `confirmation_id`（60 秒有效）；
  - 再在 `POST /v1/commands` 里带上它；
  - 确认绑定到“使用者 + 命令名 + 参数”；首次使用时绑定 request_id，同号重试仍可用，换号不能复用；
  - 只存在 apid 内存里，apid 重启即失效（失败即关闭）。
  - tradingd 的确认短语照旧逐字核对：两道确认相互独立。
- **TLS**：
  - 监听非回环地址时，必须配置证书与私钥，文件不存在就拒绝启动；
  - 回环地址可以不用 TLS（本机客户端）。
- **审计**（api.db）：
  - 认证失败、限流、令牌签发与吊销、确认签发、命令提交与结果；
  - 写审计失败时，命令不转发（503，失败即关闭）。
- **TWS 端口只绑本机**：已由 B-03a 的 ConnectionPolicy 强制，本任务补一条回归测试引用。

## 验收标准

- [ ] 无令牌、错误令牌、过期令牌、已吊销令牌都返回 401；WebSocket 同样拒绝。
- [ ] 高危命令不带确认、确认过期、确认属于别的参数或别人、确认被另一个 request_id 用过，都被拒绝且不转发。
- [ ] 同一 request_id 重试时，可以复用同一个确认。
- [ ] 非回环地址没有证书时拒绝启动。
- [ ] api.db 的令牌与审计表只追加；数据库里没有令牌明文。
- [ ] apid 运行时，token 子命令拒绝执行；在线吊销立即生效，viewer 不能吊销。
- [ ] 不信任代理转发头：限流与审计只看 TCP 对端地址。

## 计划

- 改动文件：见允许修改范围。
- 迁移：api.db 首次创建，结构版本 1。
- 风险：令牌泄露。对策：只存哈希，可吊销，有效期有上限，失败限流，局域网之外经 VPN。
- 测试：单元（令牌存储、确认、限流、配置）；集成（apid 认证与审计、CLI 与锁）。
- 回滚：revert；api.db 可删除重建，只需重新签发令牌，没有交易数据。
