# ADR-15：账户类型与风控口径（修订）

- 状态：已定（2026-10-22，Dylan）
- 修订：V4.1 第 2 章 ADR-15（建议首期用现金账户）
- 决策人：Dylan

## 背景

Dylan 的 IBKR 账户目前是**现金账户**，以后会升级为**保证金账户**（同一账户升级，不是两个账户）。Dylan 希望在
登录或操作界面有“现金 / 保证金”切换开关。

## 决策

1. **真实账户类型以 IBKR API 返回为准**。tradingd 在启动与每次重连时读取并记录，界面显示“账户类型：现金 / 保证金
   （来自 IBKR）”。界面不能“切换”真实账户类型——那只能在 IBKR 那边办理。
2. **风控口径**是系统配置，与真实账户类型分开：
   - **往更严的方向**（例如保证金账户也按现金规则：只用已结算现金、杠杆固定 1.0）：界面一键切换，立即生效，写审计。
   - **往更松的方向**（例如启用保证金口径）：只能由 Dylan 修改受保护配置（config/risk）并重启生效；
     且配置的口径必须与 API 读到的真实账户类型一致，**不一致拒绝启动**。界面上没有放宽按钮。
3. **账户类型变化检测**：运行中或重启后发现真实类型与上次记录不同（例如现金 → 保证金），立即进入 **SAFE HALT**，
   提示 Dylan 人工确认；不会静默改变口径。确认流程：Dylan 核对后修改受保护配置并重启。
4. **即使账户升级为保证金**，首期仍然：杠杆固定 1.0、禁止做空、禁止衍生品。改变这些只能由 Dylan 另行批准修改受保护
   风控参数（附录 A），并重新走对应门禁。
5. 现金账户口径：只用已结算现金规划买入（T+1 结算），风控区分已结算与未结算现金；NAV 统一折算为美元（不变）。

## 理由与代价

- 界面开关只能让系统“更保守”，永远不可能一键“加杠杆”，符合“安全可靠第一”。
- 代价：放宽口径需要重启；账户升级当天系统会停在 SAFE HALT，直到人工确认。

## 影响

- C-04：+0.5 工日（启动与重连时核验账户 ID 与类型；类型变化 → SAFE HALT；口径与真实类型不一致拒绝启动）。
- R-02：+0.5 工日（运行时“只能更严”的口径切换、审计；放宽只认受保护配置）。
- S-04：+0.5 工日（显示真实账户类型、当前口径、一键从严开关、账户 ID 与模式标识）。
- F-04：附录 A 增加“风控口径”参数，默认“现金口径”。
