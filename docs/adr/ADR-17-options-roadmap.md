# ADR-17：股票期权路线（草案）

| 字段 | 内容 |
|---|---|
| 状态 | 草案。开工排在 G7 之后，是否开工由 Dylan 决定；需单独通过 G8 |
| 日期 | 2026-11-03 |
| 起草 | 协调方按 Dylan 路线授权安排 |

## 背景

Dylan 的最终目标包括期权等多种资产。V4.1 第 1 章把后续扩展排为：股票期权 → 期货 → 期货期权，每一类都要独立排期，并单独通过 G8。
首期目标是建成可信的系统，加上一到两个经过严格检验的 ETF 策略。期权放在第二阶段。

## 决策（草案）

1. **只做有保护或风险有上限的结构，永不裸卖期权。** 按阶段推进，每一阶段都要单独通过 G8，由 Dylan 批准：
   - P1：备兑看涨（持有正股，卖出相同数量的看涨期权）、保护性看跌（持有正股，买入看跌期权）；
   - P2：风险有上限的价差（看涨或看跌的垂直价差、领口策略），最大亏损在开仓时就已确定；
   - 永远不做：裸卖看涨、裸卖看跌（包括现金担保看跌，除非 Dylan 另行批准），以及卖出跨式、宽跨式这类风险没有上限的结构。
2. **风控先行**：开仓前算出最大亏损，并计入组合风险预算；到期日、行权、指派、提前行权都要有处理流程；
   重大事件前（财报、除息）有规则约束；期权的流动性（买卖价差、未平仓量）不达标的不交易。
3. **数据与对账**：期权链、隐含波动率与希腊值的数据源；按合约、行权、指派、到期结算的方式对账；
   保证金按券商口径与本地口径各算一份，两者核对。
4. **权限**：需要 IBKR 账户开通相应的期权交易等级。开通由 Dylan 本人办理，系统只校验，不申请。
5. **复用**：继续用同一套 OMS、风控、模式管理和审计。新增期权专用的风控规则与订单类型，不另起一套系统。

## 依据

- 卖出期权本质上是承担尾部风险，平时稳定赚小钱，极端行情一次亏大钱。
  LJM 基金在 2018 年 2 月的波动率暴涨中，几天内就亏掉了大部分资产。
- 有保护和风险有上限的结构，最大亏损在开仓时就能确定，可以纳入现有的限额体系。
