# ADR-16：风控参数运行时调整（风控面板）

| 字段 | 内容 |
|---|---|
| 状态 | 已定（Dylan 本人于 2026-10-24 在项目决策卡上选择“同意折中方案”，经协调会话转达） |
| 影响范围 | R-02（参数与限额）、R-05（急停）、S 组（API 鉴权）、桌面端风控面板、arch_scan |
| 修订的原条文 | V4.1 附录 A 与 `config/README.md`：“修改只能走受保护的配置文件，AI 与任何 API 都无权提高限额” |

## 背景

Dylan 要求把风控阈值做成可调节的风控面板，实盘中也能调节。原条文禁止任何 API 提高限额；这里在不让 API
越过受保护配置的前提下，开放受控的运行时调整。

## 决定

1. **受保护配置定范围**：`config/risk/parameters.toml` 仍只由 Dylan 提交。每个阈值写明名称、单位、类型、启动值与
   硬性上下限（`hard_min` / `hard_max`）。面板只能在这个范围内调整，任何 API 都不能越过上下限。
2. **调严立即生效**：写入只追加的变更记录（时间、旧值、新值、操作者、原因）。
3. **调松须 Dylan 二次确认**：先生成待确认变更，Dylan 用独立的确认操作与确认短语确认后才生效
   （与 C-04 实盘切换确认同一机制）；身份核验在 S 组 API 鉴权时接上，此前后端只接受本机受信调用。
   **AI 没有确认入口**：确认入口不出现在任何 AI 或策略可调用的路径中，由 arch_scan 收紧规则强制。
4. **重启以保存值为准**：保存值超出新配置上下限时取更严的一端并告警，不报错退出。
5. **开关不进面板**：杠杆、做空、衍生品（含期权）、市价单、风控口径等开关仍只能改受保护配置并重启。
6. **急停独立**：R-05 的四级急停始终独立生效，不受面板参数影响。
7. **现阶段只做后端**：参数读写接口、校验、变更记录、待确认流程；界面在桌面端阶段做。数值全部由 Dylan 定，
   开发方不定任何阈值；配置缺失或不合法时风控对一切新增风险拒绝（默认最严）。

## 后果

- “方向”需要每个参数显式标注（数值越大越松还是越严），否则无法判定调严 / 调松；标注写在参数定义里，
  缺标注的参数不得进入面板。
- 变更记录与待确认变更进入账本（只追加），纳入审计与备份。
- 期权：首期不做（现货稳定后再加），衍生品继续默认禁用（Dylan，2026-10-24）。

## 补充：定期复核（Dylan 2026-10-24 确认）

- 阈值设定后长期有效（跨日、跨周、重启均沿用），不需要每天重新设定。
- 每个参数记录“上次确认”时间；Dylan 在面板上点“确认无误”即刷新（不改数值，写只追加记录）。
- 复核周期：**每月**。到期前开始在面板与日报中提醒；逾期在界面上醒目标出，并附该周期内的调整记录。
- 逾期处理：**模拟盘阶段只提醒，不影响交易**；进入实盘前由 Dylan 决定是否改为“逾期超过一定天数即停止开新仓
  （减仓与止损照常）”。
- 实现放到风控面板相关任务（S 组 API 与桌面端），后端记录与到期计算随面板后端一起做。
