# 运行手册：服务器不可用时手动撤单与平仓（S-11）

这份手册给 Dylan 本人在紧急情况下照着做：交易系统联系不上、急停按钮失效，或者你看到券商那边的订单不对劲。
原则只有一条：**先止血，再查原因**。券商端的操作永远比我们的系统更直接。

> 首期只有模拟盘（Paper）。下面的步骤在模拟盘和以后的实盘里完全一样；G7 之前请只在模拟账户里演练。

## 一、什么时候用这份手册

| 场景 | 你会看到什么 | 先做什么 |
|---|---|---|
| 断网或服务器宕机 | 网页打不开，或者一直显示“连接中断 / 数据过期”；手机收到外部心跳的“服务器失联”通知 | 第二节：在 IBKR 手机 App 或 TWS 上查看并撤掉挂单 |
| 急停失效 | 网页点了急停，但结果一直是“未知”或报错；Telegram 收到“急停执行失败”的 P0 | 第二节：直接在券商端撤单；必要时第三节平仓 |
| 订单异常 | 券商端出现你不认识的订单、数量明显不对、同一只标的有重复的买单 | 第二节：先撤掉可疑订单，再通知 Ada 查原因 |

**不要**为了“让系统恢复”去重启券商客户端或改系统配置，先在券商端把风险停住。

## 二、在券商端撤单

### 用 IBKR 手机 App（IBKR Mobile）

1. 打开 IBKR Mobile，用**和交易系统相同的账户**登录（模拟盘就选 Paper）。
2. 底部菜单进入“交易”（Trade）→“订单”（Orders），查看“未成交”（Open / Working）的订单。
3. 逐张检查：
   - **开仓买单**（Buy，限价，当日有效）：可以撤。点订单 → “取消”（Cancel）。
   - **保护性止损单**（Sell Stop / STP）：**先不要撤**。它在保护你的持仓；只有你确定要人工接管时才撤。
4. 全部处理完，刷新列表，确认想撤的订单状态变成“已取消”（Cancelled）。

- **看到什么算成功**：订单状态变成 Cancelled，列表里不再有你想撤的单。
- **出错了怎么办**：
  - 提示“订单正在撤销”（Pending Cancel）：等十几秒再刷新；券商处理需要一点时间。
  - 撤不掉，或者订单已经成交：记下订单号和时间，转到第三节决定是否平仓，并告诉 Ada。
  - 登录不了手机 App：用电脑上的 TWS，或打 IBKR 客服电话让他们帮你撤单（准备好账户信息，但**不要**把密码告诉任何人）。

### 用电脑上的 TWS

1. 打开 TWS，确认窗口顶部有你预期的账户（模拟盘显示红色 PAPER）。
2. 在“活动订单”（Activity → Orders）面板里，找到要撤的订单，右键 → “取消订单”（Cancel Order）。
3. **不要**用“全部取消”（Global Cancel）：它会连保护性止损一起撤掉。我们的系统也明确禁用全局撤单。

## 三、需要平仓时

只有在这些情况下才手动平仓：持仓已经没有止损保护、价格正在快速变化，而系统又联系不上。

1. 在 App 或 TWS 里打开持仓（Portfolio / Positions），选要卖出的标的。
2. 下**限价卖单**：价格略低于当前买一价（例如买一价 × 0.995）。尽量不用市价单，避免成交在很差的价格。
3. 如果这只标的还挂着保护性止损单，券商可能提示冲突：先撤掉止损单，再下卖单。
4. 记下你做的每一步：时间、标的、数量、价格。

## 四、事后要做的

1. 在系统恢复之前，**不要**让交易系统自动恢复交易。系统重启后默认保持 HALT（急停状态），不会自己恢复。
2. 告诉 Ada：发生了什么、你在券商端做了哪些操作（时间、订单号、数量）。
3. 系统恢复后，Ada 会运行对账：券商端的真实持仓与订单为准，系统记录里的差异会生成报告，不会被静默覆盖。
4. 确认对账没有未解释的差异后，由你决定是否解除 HALT。

## 五、演练（G7 前必须完成一次）

在模拟账户里演练一遍，并留下记录（S-11 验收要求）：

1. 让交易系统在模拟盘挂出一张开仓买单和一张保护性止损单（可以用冒烟策略的挂单样本）。
2. 假装服务器失联：在 IBKR 手机 App 里按第二节撤掉那张买单，**保留**止损单。
3. 截图记录：撤单前、撤单后的订单列表（遮住账户号）。
4. 把截图和时间发给 Ada，Ada 写进演练记录，并运行一次对账，确认系统能识别“券商端被人工撤掉的单”。
