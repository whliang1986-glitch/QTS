# R-06：TWS 订单预防设置核对（Dylan 本人操作）

TWS 自带“订单预防设置”（Precautionary Settings）。它在券商这一侧兜底：
即使我们的系统出了错，单笔数量太大、金额太高、价格偏离太多的订单也会被 TWS 拦下或要求确认。

这一道防线和系统里的风控**相互独立**，所以：
- 数值由 **Dylan 本人**决定，并在 TWS 里填写；
- 我不会替你改 TWS 设置；系统里的风控限额，也不会因为这里的数值而变化。

**什么时候核对：**
- 第一次做模拟盘下单联调之前（B-05）；
- 申请 G7（有限额的实盘）之前，再核对一次（G7 的放行条件之一）。

## 第一步：确认 API 订单不绕过预防设置

TWS 菜单：`File（文件）→ Global Configuration（全局配置）→ API → Precautions（预防措施）`

| 选项 | 应该是 | 原因 |
|---|---|---|
| Bypass Order Precautions for API Orders（API 订单绕过预防设置） | **不勾选** | 勾上之后，下面第二步的限额对系统下的单全部失效 |
| Bypass Bond warning / Redirect / Price-based volatility 等其他“Bypass”项 | 不勾选 | 同上，宁可多确认一次 |

## 第二步：填写股票的预防限额

TWS 菜单：`Global Configuration → Presets（预设）→ Stocks（股票）→ Precautionary Settings（预防设置）`

| 选项 | 含义 | 你的取值（请填写） |
|---|---|---|
| Size Limit（数量上限，股） | 单笔超过这个股数就拦下 | ________ |
| Total Value Limit（金额上限，美元） | 单笔金额超过这个数就拦下 | ________ |
| Percentage Cap / Price Cap（价格偏离上限） | 限价偏离当前价太多就拦下 | ________ |

建议的取法：
- 比系统风控的单笔上限略**宽松**一点。正常订单由系统风控把关，TWS 只拦“明显出错”的单。
- 如果比系统风控更严，正常订单就会被 TWS 拦下，表现为下单失败。
- **特别注意保护性止损**：止损单的数量等于这只标的的全部持仓，可能比单笔开仓大好几倍。
  Size Limit 和 Total Value Limit 必须不小于单只标的可能的最大持仓，否则 TWS 会拒掉止损单，持仓就没有保护。
  系统会报“缺少保护性止损”，但那时持仓已经处在无保护状态。

## 我这边会做什么

- 联调时，我会用一张明显超出 Size Limit 的模拟盘限价单，实测 TWS 会拦下（订单状态和错误码会写进 B-05 的联调记录）。
